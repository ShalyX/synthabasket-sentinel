# Sentinel — locked product brief
Date: 2026-10-08. Existing app: https://github.com/ShalyX/synthabasket.
Problem: tokenized stocks across Ondo and bStocks may differ in contract, price, conversion ratio, trading status, and executable route. Raw onchain prices are not directly comparable with underlying stock quotes.
User: a BSC wallet holder researching small, thematic baskets before trading.
Core value: inspect a thesis at the asset, issuer and execution-route level before authorizing spending.
Scope: live BSC token inventory, ratio-adjusted pricing, issuer comparison, editable basket, route preview, deterministic fail-closed guard.
Non-goals for this milestone: creating onchain basket shares, automatic orders, custodial trading, ERC-8004 agent identity, RFQ settlement, synthetic charts.
Judging: main track tokenized stocks first. Agentic Wallet / BNB Agent Studio bounty integrations only after independent proof; do not claim them already integrated.
Design: dark exchange-research editorial layout, chartreuse signals, information-dense table and prominent basket workbench; preserve separate Solana /app.
Risks: Vercel hosting showed compliance error 40304; home DNS failed before VPN. Neither demonstrates legal trading eligibility. No geo circumvention is a proposed production solution.
